# Heldenschmiede – Klang

Ambience-Klänge für die Spielleiter-App der [Heldenschmiede](../heldenschmiede/). Die App lädt einen Klang erst, wenn jemand ihn antippt – deshalb liegen die Dateien hier in einem eigenen Repository und nicht in der App.

- Die Nutzung ist **nicht kommerziell**: Die Heldenschmiede ist ein kostenloses Fanprojekt ohne Werbung.
- Die Namensnennung steht hier und im Player der App.
- Die SoundPad-Klänge von Tabletop Audio sind **nicht** enthalten – sie sind nur für die Nutzung auf tabletopaudio.com gedacht.

Wer Tabletop Audio unterstützen möchte, findet auf tabletopaudio.com den Link zu Patreon.

## Einrichten

1. Auf GitHub ein neues **öffentliches** Repository **heldenschmiede-klang** anlegen – im selben Konto wie das Repository `heldenschmiede`.
2. Diese README und alle MP3-Dateien hochladen (direkt in die oberste Ebene, kein Unterordner).
3. **Settings → Pages**: Branch **main**, Ordner **/ (root)** → Save.
4. Fertig. Die Spielleiter-App sucht die Klänge unter `../heldenschmiede-klang/`, also neben der App. Eine andere Adresse lässt sich in der App unter *Klang → Einstellungen* eintragen.

GitHub erlaubt Dateien bis 100 MB; eine 10-Minuten-Ambience hat etwa 10–25 MB.
